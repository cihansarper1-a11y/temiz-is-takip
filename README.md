# Temizİş — Ev Temizliği İş Takibi

İş, randevu, gelir ve masrafları takip etmek için çevrimdışı çalışabilen tek dosyalı bir HTML uygulaması.

## Kullanım

- `index.html` dosyasını tarayıcıda açarak yerel kullanabilirsiniz.
- GitHub Pages ile yayınlarsanız uygulamaya internet üzerinden erişilir.
- Kayıtlar, uygulamanın açıldığı tarayıcı ve cihazda saklanır; GitHub'a veya başka cihazlara otomatik senkronize edilmez.
- Telefon ve bilgisayarda ayrı kayıt tutmak istemiyorsanız uygulama içindeki **Ayarlar / Yedek** alanından JSON yedeği indirip diğer cihazda yükleyebilirsiniz.

## GitHub Pages yayını

1. GitHub'da boş bir depo oluşturun.
2. `index.html` ve bu `README.md` dosyasını deponun köküne yükleyip commit edin.
3. **Settings → Pages** bölümünde **Deploy from a branch**, `main` ve `/(root)` seçip kaydedin.
4. GitHub Pages adresi hazır olduğunda, internet bağlantısıyla bu adresten açın.

Uygulama kaynak kodu tek bir HTML dosyasındadır; ek kütüphane veya ağ bağlantısı gerektirmez.
